Update Changelog:

1. Prevented dice rolls while an auction is active to maintain proper game flow and prevent conflicts between auctions and player turns.
2. Fixed an issue where houses were not displaying correctly on the inner board (spaces 40-63).
3. Updated the auction system from a traditional player-turn-based format to a Richup-style auction system.
4. Added an automatic fold feature that activates after 12 seconds of auction inactivity.
5. Added automatic !update execution to reduce the need for manual updates.
6. Implemented automatic jail release after three turns if a player fails to roll a double.
7. Added the !jailpay command with an adjusted bail system based on the number of turns spent in jail.
8. Added the !freeloan command for Free Parking (space 20).
9. Added the !insert command, allowing additional players to join an active game session.
10. Added the !gobonus command for managing GO bonus features.
11. Added administrative controls for forcing trades between players.
12. Converted space 62 (Go To Jail) into an auction space.
13. Redesigned and repositioned map buttons to the center of the board with improved visual styling.
14. Relocated the player total display box to the right side of the board for improved visibility.
15. Expanded player support from 4 players to 6 players.
16. Added separate color styling for house addition and removal controls.
17. Improved command response performance by reducing !housestatus execution time from approximately 30 seconds to 10 seconds.
18. Improved command response performance by reducing !propertylist execution time from approximately 60 seconds to 20 seconds.
19. Fixed an issue where !jailpay could be used outside of the player's active turn.
20. Updated house management controls to allow adding or removing one house at a time instead of modifying three houses simultaneously.
21. Added property house-count display support, showing the number of houses built on each property (1-4 houses).
22. Added a restriction preventing !switch from being used with players currently in jail.
23. Updated turn-ending messages to correctly display the next player's turn (for example, "Player 3 turn" instead of "Player 2 turn ended").
24. Added smoother button transitions when switching between mortgage and redeem modes.
25. Added button-press visual effects for improved user interaction.
26. Added !housestatus to the All Players page, making house and property monitoring easier.
27. Added !rename support, allowing players to replace default player names (p1-p6) with custom names.
28. Improved !status with a cleaner layout, property names, and individual player lookup support (for example, !status p1).
29. Added the !display command to allow customization of the player names shown on the MoneyBox display (p1-name through p6-name).
30. Added a Trade Menu to improve trade management.
31. Reduced the bidding sound volume for a more comfortable user experience.
32. Increased the size of board dots to improve visibility.
33. Added full compatibility for iPad and Android tablets.
34. Removed the separate mobile page section and integrated mobile device support directly into the main page.
35. Updated the dice sound effect used when rolling the jail dice.
36. Enhanced the Trade Menu with additional commands.
37. Added a name input section for each player, requiring players to enter their name before proceeding.
38. Implemented WebSocket communication for 90% of game inputs, significantly reducing latency and improving overall responsiveness. Property and house updates are now processed in under one second.
39. Prevented mortgage and unmortgage actions after any player lands on Space 62.
40. Fixed an issue preventing players with a negative balance from trading.
41. Added automatic !housestatus updates after successful !addhouse or !removehouse actions, eliminating the need for the House button.
42. Resolved an issue that caused the Trade Menu to malfunction following the WebSocket update.
